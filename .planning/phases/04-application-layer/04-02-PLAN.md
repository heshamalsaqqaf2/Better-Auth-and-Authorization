## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Validator → caller | Validator returns error message strings that may be exposed to callers |
| Type guard → consumer | Duck-type guard checks properties, may match structurally similar objects |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Information Disclosure | ApplicationErrorValidator | mitigate | Error messages describe contract violations ("layer must be APPLICATION", "operationName must be a non-empty string") — no internal details exposed |
| T-04-04 | Spoofing | isApplicationError type guard | accept | Duck-typing intentionally matches structural shape; type guard is for runtime identification, not security enforcement. If an attacker crafts an object matching the shape, no exploit path exists since the guard only enables TypeScript narrowing |
| T-04-05 | Information Disclosure | ApplicationError.correlationId | mitigate | correlationId is an opaque branded string — no embedded PII, request details, or user data. Follows D-04 requirement for distributed tracing only |
