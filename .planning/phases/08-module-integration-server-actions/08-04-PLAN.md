<objective>
Create the Authentication module's Domain layer — repository interfaces (Command + Query), auth-specific domain error types, and aggregate types.

Purpose: Establish the domain contracts that Application UseCases depend on. Repository interfaces are pure TypeScript interfaces — no InversifyJS decorators needed here (interfaces have no runtime representation). They will be bound to implementations in the ContainerModule via Symbol.for() tokens. Domain errors carry auth-specific semantics using the existing Foundation DomainError base class.
</objective>
