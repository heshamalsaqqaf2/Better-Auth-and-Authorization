**UseCase Command pattern (from CONTEXT.md D-14):**
```typescript
class SignInUseCase {
  constructor(
    private readonly authService: IBetterAuthService,
    private readonly userRepo: IQueryAuthRepository,
  ) {}
  
  execute(dto: SignInDTO): Promise<ApplicationResult<AuthResponseDTO>> {
    // 1. Call BetterAuthService.signIn
    // 2. Map InfrastructureResult → ApplicationResult via mapInfraToAppError
    // 3. Query user details from repository
    // 4. Map DomainResult → ApplicationResult via mapDomainToAppError
    // 5. Return ApplicationResult with AuthResponseDTO
  }
}
```

**DTO shapes:**
- `SignInDTO: { email: string; password: string }`
- `SignUpDTO: { name: string; email: string; password: string }`
- `AuthResponseDTO: { user: UserDTO; session: SessionDTO }`
- `UserDTO: { id: string; name: string; email: string }`
- `SessionDTO: { id: string; expiresAt: string }`

**Error mapping rules:**
- InfrastructureResult Failure → mapInfraToAppError() to get ApplicationError
- DomainResult Failure → mapDomainToAppError() to get ApplicationError
- Unexpected errors → UseCaseExecutionError with original error as cause
</interfaces>
