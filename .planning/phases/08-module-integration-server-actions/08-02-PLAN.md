<objective>
Create the AsyncLocalStorage-based request context middleware (proxy.ts) that propagates CorrelationId across the request lifecycle.

Purpose: Every request gets a unique correlation ID that flows through middleware → Server Action → UseCase → Repository → DB. Enables end-to-end tracing without manual ID threading.
</objective>

<interfaces>

**proxy.ts contract (Next.js 16 convention per AGENTS.md):**
- File at project root: `proxy.ts`
- Exports default async function `proxy(request: NextRequest): Promise<NextResponse | undefined>`
- Initializes AsyncLocalStorage context with a generated `CorrelationId`
- Calls `NextResponse.next()` to continue the request pipeline

**RequestContext store contract:**
- Typed store shape: `{ correlationId: string; startTime: number }`
- `getCorrelationId(): string | undefined` — read from async context
- `setCorrelationId(id: string): void` — write to async context
- `getStore(): Store | undefined` — raw store access
- Export `requestContextStore` AsyncLocalStorage instance

**CorrelationId integration:**
- Generate correlation ID using crypto.randomUUID()
- Wrap the ID in the Kernel's CorrelationId branded type if the factory is importable
- If not importable (layer boundary), use a plain string with same format

</interfaces>
