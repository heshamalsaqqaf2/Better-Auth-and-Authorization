```

**Target CompositionRoot/index.ts pattern:**

```

**@injectable() decorator usage (InversifyJS + Next.js SWC):**
- Use `@injectable()` on every class resolved via DI
- Use explicit `@inject(Symbol.for(...))` on ALL constructor parameters
- SWC supports experimentalDecorators but NOT emitDecoratorMetadata, so explicit @inject() is REQUIRED
- Import `{ injectable, inject }` from "inversify"

**BetterAuthService binding rules (D-17):**
- Infra services: singleton scope (`.inSingletonScope()`)
- UseCases/Application services: transient (default — no scope decorator)

</threat_model>
