<interfaces>

**Repository implementation pattern:**
```typescript
class DrizzleAuthQueryRepository implements IQueryAuthRepository {
  constructor(private readonly db: DrizzleClient) {}
  
  async findUserByEmail(email: string): DomainResult<UserAggregate | null> {
    // 1. Wrap query in withRetry + withTimeout
    // 2. Query Drizzle with email filter
    // 3. Map row to UserAggregate via DB mapper
    // 4. Return DomainResult success with aggregate or null
    // 5. Catch Drizzle errors → InfrastructureResult Failure → map to DomainResult
  }
}
```

**DB mapper pattern:**
```typescript
function mapUserRowToAggregate(row: UserRow): UserAggregate {
  return {
    id: row.id,
    name: row.name,
    email: row.email,
    emailVerified: row.emailVerified,
    createdAt: row.createdAt,
    updatedAt: row.updatedAt,
  };
}
```

**Error handling:**
- Drizzle query errors → DatabaseQueryError
- Drizzle connection errors → DatabaseConnectionError
- All wrapped in InfrastructureResult → use mapResult helper to convert to DomainResult
- Use withRetry for transient DB failures
