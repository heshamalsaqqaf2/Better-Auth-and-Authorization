<interfaces>

**BetterAuthService contract:**
```typescript
interface IBetterAuthService {
  signIn(email: string, password: string): InfrastructureResult<SessionData>;
  signUp(name: string, email: string, password: string): InfrastructureResult<UserData>;
  signOut(headers: Headers): InfrastructureResult<void>;
  getSession(headers: Headers): InfrastructureResult<SessionData | null>;
}
```

**Error wrapping pattern:**
- Catch Better Auth errors/exceptions
- Map to specific InfrastructureError subclasses (ApiTimeoutError, ApiUnavailableError, etc.)
- Wrap successful results in InfrastructureResult success
- Use withRetry for transient operations (sign-in, sign-up)
- Use withTimeout for all operations

**Resilience wrapper integration (from Foundations Infrastructure):**
- `withRetry(operation, options?)` — retries with exponential backoff
- `withTimeout(operation, ms)` — fails after timeout
- Both return InfrastructureResult — no throws
</interfaces>
