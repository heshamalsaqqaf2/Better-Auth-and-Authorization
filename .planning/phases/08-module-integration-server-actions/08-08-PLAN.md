**Page structure (D-11):**
- Auth pages are Server Components (RSC)
- They import and render Client Component forms
- Layout wraps auth pages in a centered card with the app logo/title

**Form component pattern (D-08, D-09, D-11):**
```typescript
// Client Component form
import { useActionState } from 'react';
import { useForm } from '@tanstack/react-form';

export function SignInForm() {
  const [state, formAction, pending] = useActionState(signInAction, initialState);
  
  const form = useForm({
    defaultValues: { email: '', password: '' },
    onSubmit: async ({ value }) => {
      formAction(new FormData(/* ... */));
    },
  });
  
  // Render: Card with form fields
  // _tag matching: 
  //   state._tag === 'SUCCESS' → redirect to dashboard
  //   state._tag === 'FAILURE' → check error._tag
  //     error._tag === 'ValidationError' → inline field errors
  //     error._tag === 'SystemError' | 'AuthorizationError' → toast(error.userMessage)
  //     error._tag === 'NotFoundError' → inline message
}
```

**Error display rules (D-09):**
- `ValidationError` → fieldErrors rendered inline next to each field via `<p className="text-destructive text-sm">`
- `SystemError` → sonner `toast.error(error.userMessage)`
- `AuthorizationError` → sonner `toast.error(error.userMessage)`
- `NotFoundError` → inline banner message below the form title
- `NetworkError` → toast (same as SystemError)

**@tanstack/react-form integration:**
- Use `useForm` from `@tanstack/react-form`
- Field components use shadcn/ui Input, Label components
- Submit button uses Button component with pending state
- Form uses `onSubmit` handler that calls the Server Action

**shadcn/ui components available:**
