**Page structure (D-11):**
- Auth pages are Server Components (RSC)
- They import and render Client Component forms
- Layout wraps auth pages in a centered card with the app logo/title

**Form component pattern (D-08, D-09, D-11):**
```typescript
// Client Component form — InversifyJS is NOT used here
'use client';

import { useActionState } from 'react';
import { useForm } from '@tanstack/react-form';
import { signInAction } from '@/Modules/Authentication/Presentation/Actions/sign-in.action';
// signInAction resolves from InversifyJS internally — client doesn't know about DI

export function SignInForm() {
  const [state, formAction, isPending] = useActionState(signInAction, initialState);

  // _tag matching:
  //   state._tag === 'SUCCESS' → router.push('/dashboard')
  //   state._tag === 'FAILURE' → check state.error._tag
  //     'ValidationError' → inline field errors
  //     'SystemError' | 'AuthorizationError' → toast(state.error.userMessage)
  //     'NotFoundError' → inline message
}
```

**Error display rules (D-09):**
- `ValidationError._tag` → `fieldErrors` rendered inline next to matching fields via `<p className="text-destructive text-sm">`
- `SystemError._tag` → sonner `toast.error(error.userMessage)`
- `AuthorizationError._tag` → sonner `toast.error(error.userMessage)`
- `NotFoundError._tag` → inline banner message below the form title
- `NetworkError._tag` → toast (same as SystemError)

**@tanstack/react-form integration:**
- Use `useForm` from `@tanstack/react-form` with `useActionState`
- Field components use shadcn/ui Input, Label
- Submit button uses Button with `isPending` state
- Form uses `onSubmit` handler that calls formAction with FormData

**shadcn/ui components available:**
- `@/Shared/components/ui/card` — Card, CardHeader, CardTitle, CardContent, CardFooter
- `@/Shared/components/ui/input` — Input
- `@/Shared/components/ui/button` — Button
- `@/Shared/components/ui/label` — Label
