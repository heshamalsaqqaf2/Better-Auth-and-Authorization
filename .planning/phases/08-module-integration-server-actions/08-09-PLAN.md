<objective>
Create the user and admin dashboard pages, sign-out button component, and global + per-route error boundaries.

Purpose: Dashboards are the authenticated landing pages. User dashboard is basic welcome + sign-out (D-10). Admin dashboard is basic admin message — no RBAC in Phase 8 (D-10). Both have route-level error boundaries (D-12). The global error boundary catches anything that falls through (D-12). Sign-out button calls signOutAction which resolves from the InversifyJS container internally. UI components never import from InversifyJS directly.
</objective>
