<action>
Create `src/Core/Foundations/Presentation/Errors/presentation-error.types.ts` containing:

1. **5 variant type definitions** (`ValidationErrorShape`, `NotFoundErrorShape`, `AuthorizationErrorShape`, `SystemErrorShape`, `NetworkErrorShape`) — each with `_tag` discriminant, `userMessage: string`, `errorCode: string`, plus variant-specific fields:

   - **ValidationErrorShape**: `_tag: 'ValidationError'`, `errorCode: string`, `fieldErrors: Record<string, string[]>`, no `userMessage` (fieldErrors conveys it)
   - **NotFoundErrorShape**: `_tag: 'NotFoundError'`, `errorCode: string`, `userMessage: string`, `suggestedAction?: string`
   - **AuthorizationErrorShape**: `_tag: 'AuthorizationError'`, `errorCode: string`, `userMessage: string` (no requiredPermission per D-04)
   - **SystemErrorShape**: `_tag: 'SystemError'`, `errorCode: string`, `userMessage: string`, `severity: 'warning' | 'error' | 'critical'`
   - **NetworkErrorShape**: `_tag: 'NetworkError'`, `errorCode: string`, `userMessage: string`, `retryable: boolean`

2. **`PresentationError` discriminated union type** = `ValidationErrorShape | NotFoundErrorShape | AuthorizationErrorShape | SystemErrorShape | NetworkErrorShape`

3. **Standalone factory functions** for each variant:
   - `createValidationError(errorCode: string, fieldErrors: Record<string, string[]>)`: `ValidationErrorShape`
   - `createNotFoundError(errorCode: string, userMessage: string, suggestedAction?: string)`: `NotFoundErrorShape`
   - `createAuthorizationError(errorCode: string, userMessage: string)`: `AuthorizationErrorShape`
   - `createSystemError(errorCode: string, userMessage: string, severity: 'warning' | 'error' | 'critical')`: `SystemErrorShape`
   - `createNetworkError(errorCode: string, userMessage: string, retryable: boolean)`: `NetworkErrorShape`
All return the respective shape type as plain objects — no classes, no `instanceof`.

All shapes are plain object types — no classes, no `instanceof`.
